# 🌙 حاسبة الزكاة (Zakat Calculator)

تطبيق ويب حديث وآمن ومصمم بعناية لحساب زكاة المال وفق الأحكام الشرعية، مع دعم متابعة **النصاب** و**الحول الهجري**، وتحويل العملات بأسعار الصرف المباشرة، وتخصيص معايير النصاب والاستقطاعات، وتشفير بيانات المستخدم بالكامل لحفظ الخصوصية.

👉 **رابط المعاينة والتطبيق المباشر:** [https://anas-khalil.github.io/Zakat-Calculator/](https://anas-khalil.github.io/Zakat-Calculator/)

---

## 🌟 المميزات الرئيسية

* **🪙 مرونة معيار النصاب (ذهب عيار 24 أو فضة):**
  * **نصاب الذهب:** جلب سعر الذهب الخالص (عيار 24) تلقائيًا لتحديد قيمة النصاب الشرعي (المعادل لـ **85 جرامًا**).
  * **نصاب الفضة:** إمكانية التبديل إلى خيار نصاب الفضة (المعادل لـ **595 جرامًا** من الفضة النقية) وفق الترجيح الفقهي الأنفع للفقراء.
  * إمكانية تحديث الأسعار لايف أو إدخالها يدويًا.

* **💼 دعم المحافظ والحسابات المتعددة:**
  * إضافة مختلف الحسابات والمدخرات المالية مع اختيار عملة كل حساب.
  * تحويل تلقائي وديناميكي لجميع العملات إلى العملة الأساسية (اليورو `EUR` أو العملة المختارة) عبر APIs لأسعار الصرف الحية.

* **📉 خصم الديون والالتزامات العاجلة:**
  * قسم خاص ومستقل لإضافة الديون والالتزامات المالية المستحقة قريباً.
  * خصم إجمالي الديون تلقائيًا من إجمالي الأموال للحصول على **صافي المال الزكوي** الدقيق قبل مقارنته بالنصاب.

* **🌙 متابعة الحول الهجري وشريط التقدم:**
  * حساب مدة الحول بناءً على السنة الهجرية (354 يومًا).
  * شريط تقدم بصري (Progress Bar) يوضح نسبة اكتمال الحول ومطابقة صافي الأموال مع حد النصاب.

* **📧 إشعارات بريدية عند اكتمال الحول:**
  * دعم خيار التنبيهات البريدية التلقائية لإرسال إشعار للمستخدم فور اكتمال الحول الهجري لماله لتذكيره بوجوب إخراج الزكاة.

* **🔒 أمان عالي وتشفير كامل (Zero-Knowledge Encryption):**
  * يتم تشفير جميع الحسابات والبيانات والديون محلّياً على جهازك باستخدام مفتاح مشتق من كلمة المرور الخاصة بك (Web Crypto API / PBKDF2 & AES).
  * لا يتم حفظ أو رؤية بياناتك المالية بأسلوب النص المفتوح (Plain Text) في أي سيرفر، حتى مطور الموقع أو قاعدة البيانات لا يمكنهم الاطلاع عليها.

* **📸 حفظ السجلات واللقطات (Snapshots):**
  * إمكانية أخذ لقطة أرشيفية من حساباتك في تاريخ محدد للرجوع إليها مستقبلاً وتتبع تطور الزكاة سنة بعد أخرى.

* **📱 تصميم عصري ومتجاوب:**
  * واجهة سهلة ومستجيبة تعمل بكفاءة على جميع الشاشات (الهواتف المحمولة، الأجهزة اللوحية، والحواسيب).

## 🛠️ التقنيات والأدوات المستخدمة (Tech Stack & Tools)

* **HTML5 / CSS3:** لبناء هيكل الصفحات والتصميم المرئي العصري والمتجاوب.
* **JavaScript (ES6+):** لمنطق الحسابات، إدارة الحالة، والتفاعل المباشر مع المستخدم.
* **Firebase Firestore Database:** لتخزين وإدارة البيانات المشفرة واللقطات (Snapshots) بطريقة آمنة وسريعة.
* **Firebase Cloud Functions:** للخدمات الخلفية المؤتمتة ومجدول المهام (Cron Jobs) لإرسال الإشعارات البريدية عند اكتمال الحول.
* **Web Crypto API / PBKDF2 & AES:** لتشفير وفك تشفير بيانات المستخدم بأمان تام في المتصفح قبل حفظها.
* **REST APIs:**
  * جلب أسعار الذهب والفضة الحية مباشرة.
  * جلب أسعار تحويل العملات الأجنبية في الوقت الفعلي (Live Exchange Rates).
* **AI-Assisted Development:** تم كتابة وتطوير الكود بالاستعانة بنموذج الذكاء الاصطناعي **Claude 3.5 Sonnet**.
* **GitHub Pages:** لاستضافة التطبيق وتوفير وصول سريع ومجاني للمستخدمين.

## 📐 طريقة عمل الحاسبة والمنطق الشرعي

1. **حساب النصاب (حسب الخيار المحدد):**
   * **نصاب الذهب:** $\text{سعر جرام الذهب (24)} \times 85$
   * **نصاب الفضة:** $\text{سعر جرام الفضة} \times 595$

2. **حساب صافي المال الزكوي:**
   $$\text{صافي المال الزكوي} = \text{إجمالي المحافظ والمدخرات} - \text{إجمالي الديون العاجلة}$$

3. **شروط وجوب الزكاة:**
   * أن يبلغ صافي المال **النصاب** (ذهباً أو فضة) أو يتجاوزه.
   * أن يمضي على بلوغ النصاب **حول كامل** (سنة هجرية = 354 يومًا).

4. **مقدار الزكاة المستحقة:**
   $$\text{الزكاة المستحقة} = \text{صافي المال الزكوي} \times ٪2.5\%$$ *(أو القسمة على 40)*.
